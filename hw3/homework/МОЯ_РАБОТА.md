# Сервис уведомлений

Автор: Лобанов Максим

## Что делает программа

Программа показывает учебную отправку уведомлений через email и push. Каналы реализуют общий интерфейс `Notifier` и сохраняют отправленные сообщения в своих историях; реальной отправки нет.

## Как запустить

Нужен Go 1.22 или новее. Команды выполняются из папки `hw3`, в которой находится `go.mod`:

```bash
go run ./cmd/notify
go test ./...
```

## Проверенные случаи

1. **Успешная отправка:** `Dispatch` возвращает `nil`; email и push сохраняют соответственно `[email] Заказ готов` и `[push] Заказ готов`.
2. **Пустой текст:** `errors.Is` распознаёт `ErrEmptyMessage`; обе истории остаются прежними.
3. **Нет настройки:** push без `DeviceID` возвращает `SendError`. Через `errors.As` получаем канал `push` и причину `не задан device id`.
4. **Паника канала:** `SafeDispatch` возвращает ошибку с причиной `ErrNotifierPanic` и продолжает рассылку. Следующий push получает `[push] Заказ готов`.

## Обработка ошибок

`Dispatch` вызывает каналы по порядку и останавливается на первой ошибке. Он добавляет имя канала и сохраняет исходную причину через `%w`.

`SafeDispatch` вызывает все каналы и собирает ошибки в слайс. Каждый вызов проходит через `SafeSend`: обычная ошибка возвращается без изменений, а паника перехватывается с помощью `defer` и `recover` и превращается в ошибку с причиной `ErrNotifierPanic`. `recover` расположен вокруг отдельного вызова `Send`, чтобы после паники цикл мог перейти к следующему каналу.

В `main` функция `errors.Is` распознаёт пустое сообщение и панику даже после оборачивания, а `errors.As` извлекает `*SendError`, чтобы прочитать его поля.
