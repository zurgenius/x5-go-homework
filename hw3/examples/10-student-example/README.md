# Пример для самостоятельного повторения

Программа проверяет остатки товара. Запускайте из папки `student`:

```bash
go run ./examples/10-student-example
```

Сначала прочитайте `stock`, затем `checkStock`, затем `main`. Попробуйте предсказать результат до запуска.

```text
"чай": остаток 5
"кофе": остаток 0
"сок": проверьте название товара
ошибка ввода: не задано название
```

В `stock` пустое название создаёт `*ProductError`, отсутствующий товар возвращает известную `ErrProductNotFound`, найденный товар возвращает количество и nil. Обёртка в `checkStock` сохраняет причину через `%w`. Вызывающий код использует Is и As.

Нулевой остаток кофе допустим. Второй результат чтения map сообщает, существует ли ключ. Порядок запросов задаёт слайс, поэтому вывод стабилен.

Попробуйте добавить товар с остатком 2, затем запрос несуществующего товара. Измените текст контекста в checkStock и убедитесь, что Is и As продолжают находить причину и тип. Это законченный пример для повторения, домашнюю работу выполняйте отдельно в practice.
